## Coloring

For CSS, a great source for snippets is this [Github repo](https://github.com/Dmitriy-Shulha/obsidian-css-snippets/tree/master/Snippets) or checking out this [forum thread](https://forum.obsidian.md/t/how-to-achieve-css-code-snippets/8474/152)

For coloring text, you can use Deathau’s [Notation Colour Blocks](https://github.com/deathau/obsidian-snippets#notation-colour-blocks) which will look in edit mode like:

````go
``` note-purple
This text will be pruple
```
````

or

```php-template
<span class="purple"> This note will be purple </span>

<font color="purple" size="4"> This note will be purple </font>
```

<font color="purple" size="4"> This note will be purple </font>

Alternatively you can use the [8+8 highlight snippet](https://github.com/steveyang331/Obsidian-css/tree/main/8%2B8%20highlight%20colors) to color highlighted, italicized or bolded text using tags

e.g.

```graphql
#h/red **This bold text will be red**
#h/red ==This highlighted text will be highlighted red==
#h/red *This italicized text will be red*
```

#h/red **This bold text will be red**
#h/red ==This highlighted text will be highlighted red==
#h/red *This italicized text will be red*
